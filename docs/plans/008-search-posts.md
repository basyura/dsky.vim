# 008 投稿検索の追加

## 目的

投稿表示バッファで `q` を押すとコマンドラインで検索語の入力を待ち、実行後に検索結果でバッファを書き換える。

## 操作と動作

- 投稿表示用の dsky バッファのノーマルモードで `q` を押すと、コマンドライン領域でキーワードの入力待ちにする。`:DSkySearch` などのコマンド名は表示しない。
- `q` は投稿表示用の dsky バッファ専用のバッファローカルキーとし、通常の編集バッファには割り当てない。
- 検索語を入力して Enter を押すと Bluesky の投稿検索を実行する。
- 空白を含む検索語や日本語をそのまま検索へ渡す。
- 検索結果は既存の投稿表示形式で、既存の dsky バッファを置き換える。
- 検索結果が 0 件の場合は以前の投稿を消去する。
- 入力を Esc で取り消した場合や、検索語が空白のみの場合は検索せず、表示を維持する。
- 検索に失敗した場合はエラーを表示し、既存の表示を維持する。
- 検索結果表示中の `<Leader><Leader>` は、入力待ちに戻らず同じ検索語で再検索する。0 件の場合も検索語を保持する。
- 検索語は表示バッファに保持し、タイムライン・通知・投稿者別表示への切り替え時に解除する。キャンセルや検索失敗では変更しない。

## 修正案

1. `plugin/dsky.vim` に検索入力処理を呼び出す `<Plug>(dsky_search)` を追加する。`DSkySearch` コマンドは追加せず、マッピングからの呼び出しも画面に表示しない。
2. `autoload/dsky/buffer.vim` にバッファローカルの `q` マッピングを追加する。投稿作成バッファの既存の `q` は維持する。
3. `autoload/dsky.vim` にキーワード入力処理を追加し、入力確定後に検索する。`autoload/dsky/api.vim` に検索の呼び出し処理を追加し、取得成功後に既存のバッファ描画処理を使う。
4. `denops/dsky/main.ts` に検索のディスパッチ処理を追加する。
5. `denops/dsky/consts.ts` と `denops/dsky/api/feed.ts` に `app.bsky.feed.searchPosts` の呼び出しを追加する。実装前に公式仕様を確認し、検索語を適切に URL エンコードして、レスポンスを既存の `Post` へ変換する。
6. 既存のテスト構成に合わせて検索処理と操作の回帰テストを追加する。
7. 再読み込みを `dsky#reload()` に集約する。検索時はバッファ描画に検索語を渡して保存し、通常の描画では解除する。検索語がある場合は再検索し、それ以外は従来どおりタイムラインを取得する。

## 検証

- dsky バッファのノーマルモードで `q` がキーワードの入力待ちになり、コマンド名が表示されないこと。
- 通常の編集バッファに検索用の `q` が割り当てられず、投稿作成バッファの既存操作にも影響しないこと。
- 日本語、空白、引用符、検索条件に含まれる記号が壊れずに渡ること。
- 検索結果が既存の投稿を置き換え、0 件の場合にも以前の投稿が残らないこと。
- 空白のみの入力や通信エラーで既存の表示が失われないこと。
- `sh scripts/test.sh` を実行し、既存機能への影響を確認する。
